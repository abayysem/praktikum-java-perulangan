## Deskripsi
Latihan mandiri ini merupakan tugas pemrograman Java menggunakan Apache NetBeans. Program terdiri dari empat latihan tentang perulangan dan method.

## Daftar Latihan

### Latihan 1 – Nomor Urut Barang
Menggunakan perulangan `for` untuk menampilkan nomor barang dari 1 sampai 10 dan dari 10 sampai 1.

### Latihan 2 – Simulasi Stok
Menggunakan perulangan `while` untuk mengurangi stok awal sebanyak 5 hingga habis.

### Latihan 3 – Method Kembalian
Membuat method `hitungKembalian()` untuk menghitung uang kembalian berdasarkan uang bayar dan total harga.

### Latihan 4 – Method Daftar Barang
Membuat method `tampilkanDaftarBarang()` dengan tipe kembalian `void` untuk menampilkan barang sesuai jumlah pembelian.
